# Farmalegends

Aula de repaso de Farmacología Médica, organizada por módulos temáticos e interfaces interactivas.

## Abrir localmente

Abre `aula-legend/index.html` en un navegador. El proyecto es estático y no requiere un servidor backend.

## Contenido

- Aula Magna y navegación principal.
- Compendio farmacológico.
- Laboratorio de simulación e interacciones documentadas.
- Módulos de epilepsia y Parkinson/esquizofrenia.
- Casos clínicos y recetario.

Los PDF de lecturas y temarios no se incluyen en este repositorio; se mantienen localmente como material de consulta.
